### 知見

- baseline は `.claude/` 配下（dvignore済み）のため**マシンローカル＝Mori専用ガード**。Hiruta側には配布されない（仕様。GUI の Submit Content はそもそもフック対象外）。
- Git Bash から `cmd //c commit.bat` は cwd 解決に失敗することがある。`cmd /c 'E:\...\commit.bat < NUL'` のように**絶対パス＋cmd内リダイレクト**が確実。
- PreToolUse で複数フックを並列実行する場合、それぞれに同じ stdin JSON が渡り、どれかが exit 2 ならブロックされる（check-impl-log と共存可）。
