## CS-3 照合判定関数（色一致判定）実装

Vault側セッションで確定した設計境界（しきい値=外部パラメータ、配置=`FColoursColorBase` の static 関数）に基づき実装。

### 実施内容

1. `FColoursColorBase` に `ColorDistance(RgbA, RgbB)`（ユークリッド距離、RGBを[0,1]正規化してから計算）と `IsColorMatch(RgbA, RgbB, Threshold)` を追加。既存 `CMYtoRGB`/`RGBtoCMY` と同じDoxygenスタイルで実装。
2. `FColoursLightValue`/`FColoursInkValue` それぞれに `GetRGB()` アクセサを追加（Light は R,G,B を直接返す、Ink は既存 `CMYtoRGB` を再利用）。
3. `ColourType.md` に新規APIの説明を追記（変換ロジック節・各型のAPI節）。
4. `BlueprintCallable` は付与せず（指示書通り、既存演算operator群と同様プレーンC++ static）。

### 発生した問題

- **問題**: 実装完了後、Coloursモジュールのビルド確認ができなかった。
- **原因**: プロジェクトは UE5.3 想定（`Colours.uproject` EngineAssociation、`Target.cs` の `BuildSettingsVersion.V4`/`Unreal5_3` はいずれも5.3向けの設定で正しい）だが、ビルド実行時に呼び出されたUnrealBuildToolがUE5.8系のもので、「Colours has build products in common with UnrealGame」という設定不一致エラーが発生。
- **調査内容**: `.uproject`/`Target.cs` の設定自体はプロジェクトの意図（5.3ダウングレード）と一致していることを確認。マシン上のUEインストール先を `Program Files` 配下で探索したが該当パス見当たらず、原因の切り分けは持ち越し。CS-3実装コード自体にはコンパイルエラーの報告なし。
- **解決方法**: 未解決。ビルド確認はcode-reviewerによる目視レビュー（数式の手計算トレース・型安全性・includeの整合性確認）で代替し、実機（UEエディタ）でのビルド確認は別途持ち越し。調査事項は [[Claudeと一緒にやること]] に追記済み。
