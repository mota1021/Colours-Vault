# Colours — ドキュメント閲覧ガイド（Hiruta向け）

> **目的**: Hiruta が仕様・実装ログ・タスクにアクセスできる状態を作る。
> **受け入れ条件**: Hiruta が以下の手順で実際にドキュメントを閲覧できたことを口頭/画面共有で確認。

---

## 1. セットアップ手順

### 1-1. Diversion (dv) をインストールする

- Diversion の公式サイトからインストーラーを取得し、インストールする。
- インストール後、`dv --version` でバージョンが表示されることを確認。

### 1-2. shared リポジトリをローカルに同期する

Mori から **リポジトリURL** を受け取り、任意のローカルフォルダに同期する:

```
dv clone <リポジトリURL> <同期先フォルダ>
```

以後の更新は以下で取得:

```
dv pull
```

### 1-3. Obsidian でフォルダを開く

1. Obsidian を起動し「Open folder as vault」を選択。
2. 同期先フォルダ（`shared/`）を指定する。
3. Vault が開いたら完了。

## 3. 更新の受け取り方

Mori が変更をコミット後、以下で最新を取得:

```
dv pull
```

定例ミーティング（週1回）前に pull しておくと差分を確認しやすい。

---

## 4. 備考

- `shared/` フォルダは **Mori が更新する読み取り専用リポジトリ**。Hiruta は pull のみ。
- ドキュメントに疑問・気づきがあれば定例またはDiscord/LINEで連絡。
