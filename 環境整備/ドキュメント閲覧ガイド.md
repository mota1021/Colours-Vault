# Colours — ドキュメント閲覧ガイド

---

## 1. セットアップ手順

### 1-1. Diversion (dv) をインストールする

- Diversion の公式サイトからインストーラーを取得し、インストールする。
- インストール後、`dv --version` でバージョンが表示されることを確認。

### 1-2. shared リポジトリをローカルに同期する

Mori から **リポジトリURL** を受け取り、任意のローカルフォルダに同期する:

```
dv clone <リポジトリURL> <同期先フォルダ>
```

以後の更新は以下で取得:

```
dv pull
```

### 1-3. Obsidian でフォルダを開く

1. Obsidian を起動し「Open folder as vault」を選択。
2. 同期先フォルダ（`shared/`）を指定する。
3. Vault が開いたら完了。
