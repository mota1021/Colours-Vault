# Colours — ドキュメント閲覧ガイド

shared リポジトリのドキュメントを閲覧するための環境セットアップ手順。

---

## 1. セットアップ手順

### 1-1. Diversion (dv) をインストールする

- Diversion の公式サイトからインストーラーを取得し、インストールする。
- インストール後、`dv --version` でバージョンが表示されることを確認。

### 1-2. shared リポジトリをローカルに同期する

管理者からリポジトリURLを受け取り、任意のローカルフォルダに同期する:

```
dv clone <リポジトリURL> <同期先フォルダ>
```

以後の更新は以下で取得:

```
dv pull
```

### 1-3. Obsidian をインストールする

- 公式サイト（[obsidian.md](https://obsidian.md)）からインストーラーを取得し、インストールする。無償。

### 1-4. shared フォルダを Vault として開く

1. Obsidian を起動し「Open folder as vault」を選択。
2. 同期先フォルダ（`shared/`）を指定する。
3. Vault が開いたら完了。

### 1-5. Dataview プラグインを導入する

Obsidian の設定はリポジトリと同期されないため、各自でインストールする。

1. 設定 → コミュニティプラグイン を開き、制限モードをオフにする。
2. 「閲覧」から `Dataview` を検索し、インストール → 有効化。
3. `未決事項一覧` などの自動集約ビューが正しく表示されれば完了。
