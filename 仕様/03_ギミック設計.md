# ギミック設計

## 導入シーケンス（ゲームフロー）

| Phase | タイミング | 内容 |
|---|---|---|
| Phase 1 | 序盤 | 「光」のギミックのみ。加法混色の基本を学習。 |
| Phase 2 | 中盤 | 「インク」のギミックが登場。減法混色の基本を学習。 |
| Phase 3 | 中盤以降 | 光とインクが組み合わさった複合ギミック。ルールの使い分けを要求。 |

## Phase 1 ギミック詳細（導入ステージ）

1. **ライト拾い＋壁照射**: ライトを拾うと壁の穴がリアルタイムに変化する。光が当たった部分が消えることを視覚的に学習させる。色の異なる壁を置くことで「消える部分・消えない部分」を区別させる。
2. **動くスポットライト**: 照らされたオブジェクトが消える。タイミングよく通り抜けたり、足場が消える前に次に飛んだりするアクション要素。
3. **感光部パズル**: 光を感光部に当てて扉を開ける。パズル的な光の誘導が基本となる。
