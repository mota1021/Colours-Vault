# 仕様 インボックス

> **使い方**: 仕様として詰めたいアイデアをここに書く。「仕様インボックスを整理して」と依頼するとClaudeが適切な仕様ファイル（01〜04）に統合するか、新ファイルを作成する。
>
> **アイデアプール（`999_アイデアプール.md`）との違い**:
> - `999_アイデアプール.md` → 「面白そう」レベルのゆるい発想の退避庫
> - このファイル → **仕様として具体的に決めたい**内容の入口。01〜04に落とす前提。
>
> **確定版仕様**: [[01_混色システム]] / [[02_プレイヤー]] / [[03_ギミック設計]] / [[04_光源システム]]

---

## 記入テンプレート（コピーして使う）

> **内容**だけは必ず書く。他は「分かる範囲でOK」。空欄でも出してOK。

```
### [アイデアのタイトル]
- **対象システム**: 混色 / プレイヤー / ギミック / 光源 / 新システム（名前:　）
- **内容**: 〔何をしたいか・どんなルールか。これだけは書く〕
- **狙い**: 〔なぜ入れたいか・どんな体験や問題解決につながるか〕
- **既存仕様との関係**: 〔絡む既存ルール、矛盾しそうな点があれば〕
- **確定度**: 💡思いつき / 🤔方向性は固い / ✅確定として入れたい
- **未決・相談したい点**: 〔決めきれてない点〕
```
