# ファイル命名・ディレクトリ規約

Colours プロジェクトのドキュメント（Vault 内）に適用する命名・構成ルール。
コード/アセットの命名は対象外（→ [[コーディング規約]] / [[アセット命名規約]]）。

---

## 1. 基本方針

- **「読み順・優先順に意味があり、項目が増えていく」カテゴリは番号を振る**（例: 仕様、実装ステップ、ステージ）。
- **辞書的に名前で引くもの・固有名・時系列ログは番号を振らない**（例: 規約集、人物ページ、日次ログ）。
- 1ディレクトリ＝1カテゴリ。階層はディレクトリで表現する。
- `_` プレフィックスは**原則禁止**。番号または内容を表す名前を使う。**テンプレートファイル・テンプレートディレクトリは例外**（`_` を付けてファイラ上部にまとめる）。

---

## 2. 番号フォーマット（番号を振るカテゴリ）

- **3桁**。1の位はバッファとして `0` 固定 → `010, 020, 030 …`（10刻み。間に挿入余地を残す）。
- 100 を超える規模になったら、それはカテゴリ分割のサイン → サブディレクトリを切る。
- **階層番号は最大2段**：子は `[直近親の末尾番号].[自番号]`。孫以降も直近親1つ分まで連結し、それ以上はつなげない。フォルダ内で一意であれば十分。
  - 例: `020_ライト機能/` の子ステップ `020.020_ライントレース検知/`、その中の別文書 `070.010_実装計画.md`（親番号 `020.070` の子なので `070.010`）。
- **フォルダノート（ディレクトリ概要）はディレクトリ同名**（`[ディレクトリ名].md`）。Obsidian のタブ・グラフ・検索で識別しやすくする。
- 区切り文字：番号と名前の間は `_`（アンダースコア）、階層番号間は `.`（ドット）。

**例**
```
仕様/
  000_概要と規約.md          ← 仕様ルート索引（特例名）
  010_混色システム.md
  020_プレイヤー/
    020_プレイヤー.md         ← フォルダノート（ディレクトリ同名）
    020.010_モノを拾う.md
  030_ギミック/
    030.010_ライト/
      030.010_ライト.md       ← フォルダノート（ディレクトリ同名）
      010.010_懐中電灯.md     ← 孫：「直近親 030.010 の末尾 010」+「自 010」= 010.010
      010.020_サーチライト.md
```

## 3. 特殊ファイル

### テンプレートファイル
- 雛形：`_[名前]_template.md`（先頭 `_` でファイラ上部にまとめる）
- input 雛形：`_[名前]_input_template.md`
- テンプレートディレクトリ：`_template/`
- 新規作成時にコピーして使う。中身を直接編集しない。

### input / output 2ファイル運用
確定文書（Claude整形）とラフ（ユーザー記入）を分離する。

| 種別 | ファイル名 | 誰が書くか |
|---|---|---|
| output（確定） | `[名前].md` | Claude が整形 |
| input（ラフ） | `[名前]_input.md` | ユーザーが気軽に |

### 日付サフィックス
時系列で量産されるログは `[名前]_YYYYMMDD.md`（番号は振らない）。

## 4. ディレクトリ別 適用方針

| ディレクトリ | 番号 | 命名ルール |
|---|---|---|
| `仕様/` | ◯ | 3桁・最大2段番号。フォルダノートはディレクトリ同名 |
| `実装ログ/` | ◯ | 機能dir・ステップdirとも番号化（最大2段）。フォルダノートはディレクトリ同名。テンプレートは `_template/` |
| `level_design/` | ◯ | ステージは `010_Stage1/`、プロトタイプは `000_プロトタイプ/` 等。テンプレートは `_` プレフィックス |
| `規約/` | ✕ | 内容を表す名前（`〜規約.md` `〜フロー.md`） |
| `個人ページ/` | ✕ | 人名ディレクトリ。テンプレートは `_template_member/` |
| `個人計画/` | ✕ | 索引・計画は名前、日次/週次ログは日付サフィックス。テンプレートは `_テンプレート/` |
| `shared/` 直下 | △ | 原則は内容を表す名前（`現在地.md`, `構造マップ.md` 等）。`999_アイデアプール.md` のみ例外的に番号付き（常に末尾＝999固定）。順次番号付与を検討中。 |

## 5. 改名の手順

リネームは手動編集せず**スクリプトで一括変換**し、wikiリンク・パス参照も同時更新する。
実施後は git＋Diversion 両方へコミット。

> 実績：
> - `shared/仕様/` 命名規則統一（2026-06-24 / commit `1c7b697`）
> - 全ディレクトリへの一括適用（2026-06-24 / commit `2655840`）
> - フォルダノート同名化・番号2段化・テンプレート`_`化（2026-06-24 / 本コミット）
