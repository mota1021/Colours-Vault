# Colours — アセット命名規約

> UE公式推奨に準拠しつつ、Colours固有の分類を追加。

---

## プレフィックス一覧

### Blueprint

| プレフィックス | 種別 |
|---|---|
| `BP_` | Actor Blueprint（メインのゲームオブジェクト） |
| `BPC_` | Blueprint Component |
| `BPFL_` | Blueprint Function Library |
| `BPI_` | Blueprint Interface |

### アセット

| プレフィックス | 種別 |
|---|---|
| `M_` | Material |
| `MI_` | Material Instance |
| `SM_` | Static Mesh |
| `T_` | Texture |
| `S_` | Sound |
| `WBP_` | Widget Blueprint |
| `DA_` | Data Asset（StaticData / 設定値保持用） |
| `DT_` | Data Table |

### レベル

| 種別 | 命名パターン | 例 |
|---|---|---|
| Persistent Level | `L_<ステージ名>_P` | `L_Stage1_P` |
| SubLevel | `L_<ステージ名>_<用途>` | `L_Stage1_Geometry`, `L_Stage1_Lighting` |

## 運用ルール

- 新規アセット作成時は必ず上記プレフィックスを付与する。
- フォルダは用途ごとに上記に従い配置する。新カテゴリが必要な場合は Mori が本ファイルに追記する。
