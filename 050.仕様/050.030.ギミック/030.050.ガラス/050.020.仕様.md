# 仕様: ガラス

## 概要・目的

色付き半透明のガラス素材ギミック。ライトの光がガラスを透過する際に**色フィルタ**として作用し、光の色を変える（加法混色ではない）。「ガラスの色を使って光の色を変える」というパズル操作を実現する。

## 挙動ルール

### 光の透過とフィルタ（乗算モデル）

- ガラスの透過率を (T_R, T_G, T_B)、入射光を (R, G, B) とすると、透過光 = (R×T_R, G×T_G, B×T_B) を正規化した値になる。
  - 例: 透過率(1,3,7)のガラスに紫の光(255,0,255)を当てると → (36,0,255) のような青寄りの紫になる。
- しきい値による色の一致判定（CS-3照合判定関数の流用）は不採用。透過後の色は連続的な減衰で決まる。
- 透過後の光は変化した色のまま、先にあるオブジェクト（消える壁・光センサー等）に作用する。
- 光源や照射角度の変化にリアルタイムに追従する（可逆）。

> 透過の伝播処理（多ホップ・始点管理・Intensity/DamageValueの扱い）→ [[創作/ゲーム/Colours/shared/050.仕様/050.010.カラーシステム/010.010.光/010.050.伝播/050.020.仕様|光の伝播]]

### 当たり判定

- ガラス自体に当たり判定があり、壁として塞ぐ（プレイヤーは通り抜けられない）。

### スコープ（ステージ1）

- ステージ1ではプレイヤーライト同士の直接混色は使用しない（ガラス透過混色のみが混色手段として機能する）。
