# ライト — 共通仕様

ライト種別に共通する実装方針・インターフェースを定義する。

---

## 作り方の方針

以下のパラメータを外部から指定可能にする。

| パラメータ | 説明 |
|---|---|
| 光の強さ（power） | ライト固有の光源強度（距離減衰などの影響を受ける前の値） |
| 最大照射距離 | 光が届く最大距離 |
| 減衰開始距離 | この距離を超えると光が減衰し始める |
| 照射角度 | 円錐の開き角 |
| 色 | [[光.000.index\|カラーシステム：光]] に準拠した単色（RGB） |

### power と Intensity の関係

- **power（光の強さ）**: 光源が固有に持つパラメータ。距離減衰などの影響を受ける前の値。
- **Intensity**: power が距離減衰などの影響を受けた後の、光が実際に持つ明るさ。`power × 距離減衰 = Intensity`。
- 距離減衰の適用箇所: 発光源から対象までの距離に応じて power を減衰させ、その結果を Intensity として壁・センサー・ガラス等に渡す。
