# ライト — 共通仕様

ライト種別に共通する実装方針・インターフェースを定義する。

---

## 作り方の方針

以下のパラメータを外部から指定可能にする。

| パラメータ | 説明 |
|---|---|
| 基礎輝度 | ライト固有の器具輝度（距離減衰前の値） |
| 最大照射距離 | 光が届く最大距離 |
| 減衰開始距離 | この距離を超えると光が減衰し始める |
| 照射角度 | 円錐の開き角 |
| 色 | [[010.010.光/010.000.index\|カラーシステム：光]] に準拠した単色（RGB） |

### 基礎輝度と Intensity の関係

- 「光の強さ」という独立パラメータは持たない。**基礎輝度 × 距離減衰** の計算結果を、そのまま照射する光の `Intensity` に書き込む。
- 距離減衰の適用箇所: 発光源から対象までの距離に応じて基礎輝度を減衰させ、その結果を Intensity として壁・センサー・ガラス等に渡す。
