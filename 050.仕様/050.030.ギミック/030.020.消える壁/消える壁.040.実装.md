# 実装: 消える壁

## 実装方針

- `AErasableWall` は壁をセル分割し、セル単位のコリジョン有効／無効で部分的な通過可否を管理する。
- 光源側はセルへの到達判定と `FColoursLightValue` の搬送までを担当し、色に対して壁がどう反応するかは `AErasableWall` 側で判定する。
- 壁色は `FColoursInkValue` で保持し、色一致判定時に RGB へ変換する。
- 到達した光と壁色は `FColoursColorBase::IsColorMatch` で照合し、一致したセルだけコリジョンを無効化する。
- 色一致しきい値はカラーシステム共通の `UDeveloperSettings` で保持する。初期値は `0.3`。
- 消去用の断面表示は、色ゲートを通って実際にセルが消えた場合だけ有効にする。
- `ADynamicErasableWall` は本色ゲートの対象外とする。

## 復活時の押し出しの安全規定

1. 押し出しはセル単位ではなくキャラ・物体単位で1回。その更新で復活したい全セル（複数の壁・複数の光源にまたがっていても）を1つの復活領域（合算）として扱い、押し出し先と量を1回だけ算出する。
2. 速度を与えない位置補正として実行する（物理インパルス禁止）。押し出し後の速度は押し出し方向成分をゼロにクランプする。
3. 移動はコリジョンを尊重したスイープ移動で行い、押し出した先が別の壁の中にならないようにする。
4. 押し出し距離に上限を設け、超過時（深く埋まりすぎ）は「押し出し不能」とみなしダメージ／リスポーン側へ倒す。押し出し距離上限は未定（実装時に決定）。

## セル分割の粒度

- 消去判定は「セル中心が光の形状体積内か」の数式判定（現行3×8×4=96セル）。分割数は消去解像度と判定コストのトレードオフパラメータ。

## 実装状況

- 2026-09-20 にローカル UE5.8.0 の Development Editor / Win64 ビルドと PIE 確認を完了。

## 実装ログ

### 2026-09-20 色ゲート統合確認

- 白ライト + 既定白壁: 消える。
- 赤ライト + 赤壁: 消える。
- 青ライト + 赤壁: 消えない。
- 光を外す: 復活する。
- 異色時: 消去断面の見た目も出ない。
- UEColours PR #4 は master へマージ済み。
