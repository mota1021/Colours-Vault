# 演出・UI: インタラクト

## 演出

- 現在の選択対象となっているインタラクト可能なオブジェクトの輪郭を強調表示する。
- PC（プレイヤーキャラクター）の向きによって選択対象が切り替わったときは、強調対象も追従する。
- カメラの向きだけを変更した場合は、強調対象は切り替わらない。
