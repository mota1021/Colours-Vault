# 演出・UI: インタラクト

## 演出

- 現在の選択対象となっているインタラクト可能なオブジェクトの輪郭を強調表示する。
- 複数候補が存在しても、輪郭を強調表示するのは現在の選択対象1つのみとする。
- 選択対象が切り替わったときは、強調対象も追従して切り替わる。

## 操作

- インタラクト入力のキーボード割り当ては **Fキー** とする。
