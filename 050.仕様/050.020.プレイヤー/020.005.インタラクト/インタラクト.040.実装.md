# 実装: インタラクト

## 実装方針

### 機能の所有

- プレイヤー側のインタラクトコンポーネントが、インタラクト候補一覧と現在の選択対象を管理する。
- プレイヤー側に、プレイヤーへ追従するコーン型のインタラクト判定範囲を持たせる。
- オブジェクト側は `IInteractable` インターフェースを実装する。
- 固有処理の実体はインタラクトコンポーネントが持ち、`IInteractable` の実装はそのコンポーネントへ委譲する。
- 個別のインタラクトアクション（拾う等）は、インタラクトコンポーネントの派生クラスとして実装する。

### 設定DataAsset

- プレイヤーキャラクターは、プレイヤー全体の設定入口となる **PlayerCharacter DataAsset** を1つ参照する。
- PlayerCharacter DataAsset は、機能別設定として **PlayerInteract DataAsset** をメンバーに持つ。
- インタラクトのコーン判定範囲、選択切替距離の閾値、閾値境界条件は PlayerInteract DataAsset に保持する。
- インタラクト機能は Project Settings の DeveloperSettings から値を取得せず、PlayerCharacter DataAsset 経由で PlayerInteract DataAsset を受け取る。

### 候補収集

- プレイヤー側のコーン型判定範囲に入ったインタラクト可能オブジェクトを候補一覧へ追加し、範囲から出たら除外する。
- **候補を集める処理と、候補から選択対象を決める処理は分離する。**

### 選択ロジック

- 現在の選択方式では、候補とPCの距離を比較する。
- 現在の選択対象が有効な間は、別候補が設定した切替距離の閾値だけ近くなった場合にのみ選択対象を切り替える。
- 距離差が閾値と等しい場合の扱いは外部設定で切り替えられるようにする。
- **選択ロジックは独立した処理単位に閉じ込め、候補収集・入力・固有処理側が具体的な優先判定方法へ依存しない構造にする。**
- 将来、距離以外の判定へ変更する場合は、選択ロジックだけを差し替えられるようにする。
- 選択対象が変わったときは、輪郭強調の対象も切り替える。

### 入力

- インタラクト用に独立した `Interact` Input Actionを用意する。
- キーボードでは Fキーを割り当てる。

### 実行とクールタイム

- インタラクト実行時は、選択対象の `IInteractable` を通じて固有処理へ委譲する。
- クールタイム制御は共通の仕組みを利用する。
- クールタイムの適用条件と時間は各インタラクトコンポーネント側で管理する。
