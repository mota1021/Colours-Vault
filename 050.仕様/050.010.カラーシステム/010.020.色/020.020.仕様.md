# 仕様: インク

## 概要・目的

色（インク、減法混色）を内部パラメータとして扱う方法を定義する。混色・色の変化・ダメージ計算を統一的なルールで処理する。

> 光（加法混色）→ [[創作/ゲーム/Colours/shared/050.仕様/050.010.カラーシステム/010.010.光/010.000.index|光]]
> ダメージ計算 → [[../050.040.ダメージシステム/040.000.index|ダメージシステム]]

---

## 挙動ルール

### 色の数値化方針

- 色パラメータ = **C / M / Y の独立した int32 × 3**（値域は 0〜255 に縛らない）
- **「濃さ」** = `(C + M + Y) / DamageMax`（独立した 4 つ目のパラメータではない）

### ダメージ計算

- **DamageValue = C + M + Y**（合計値）：攻撃時のダメージ量として使用
- **DamageMax**: オブジェクトごとのパラメータ。表示の正規化とダメージキャップに使用

### インクの合成ルール

- CMY 各値を加算する
- DamageMax は足される側（左辺）を引き継ぐ

### CMY → RGB 変換

カラーシステム index の CMY → RGB 変換式を参照。

### 色一致判定ルール

- CMY → RGB 変換後、RGB 空間でユークリッド距離を計算する

### インク → 光 変換

```
RGB:          CMY → RGB 変換式を使用
DamageValue:  C + M + Y（インクのDV）
Intensity:    デフォルト 1.0（呼び出し側が都度指定可）
```

### 光 → インク 変換

カラーシステム index の RGB → CMY 変換式を参照。

## パラメータ

| パラメータ | 備考 |
|---|---|
| C / M / Y | 各 int32。値域は任意 |
| DamageMax | オブジェクトごとの上限値。表示正規化とダメージキャップに使用 |
