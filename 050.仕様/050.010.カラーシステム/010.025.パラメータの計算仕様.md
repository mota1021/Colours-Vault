## CMY ↔ RGB 変換

### CMY → RGB（表示・変換共通）

```
R = 255 × (1 - C / DamageMax)
G = 255 × (1 - M / DamageMax)
B = 255 × (1 - Y / DamageMax)
```

- DamageMax: 対象オブジェクトのパラメータ
- 結果は [0, 255] にクランプ

### RGB → CMY（光 → インク 変換時）

```
sum = (1 - R/255) + (1 - G/255) + (1 - B/255)

sum = 0（白光）の場合: インクを生まない
sum > 0 の場合:
  C = DV_光 × (1 - R/255) / sum
  M = DV_光 × (1 - G/255) / sum
  Y = DV_光 × (1 - B/255) / sum
```

- C+M+Y = DV_光 が保たれる
- CMY → RGB → CMY の往復で元の値に戻る（DV一致の前提）

## 光の演算ルール

### 複数光の合成

```
① 各光の RGB を [0, 1] に正規化（÷255）
② normalize(RGB) × Intensity を計算
③ 各光のベクトルを加算
④ 合計ベクトルを再正規化して色方向を決定
⑤ 合成 Intensity = Σ 各光の Intensity
⑥ 合成 DamageValue = Σ 各光の DamageValue
```

- 合成結果を1つの光として壁・センサーに照射する

### 光の減算

- RGB 各値を減算する（下限 0 にクランプ）
- Intensity・DamageValue は引かれる側（左辺）を維持する

---

## インクの演算ルール

### インクの合成

- CMY 各値を加算する
- DamageMax は足される側（左辺）を引き継ぐ

---

## 光 ↔ インク 変換

### インク → 光

```
RGB:          CMY → RGB 変換式を使用（上記参照）
DamageValue:  C + M + Y（インクの DV）
Intensity:    デフォルト 1.0（呼び出し側が都度指定可）
```

### 光 → インク

上記 RGB → CMY 変換式を使用。

---

## 色一致判定

光・インクともに RGB 空間に変換してから判定する。

```
① RGB をそれぞれ [0, 1] に正規化
② ユークリッド距離を計算: d = √(ΔR² + ΔG² + ΔB²)
③ d ≦ しきい値 → 色一致（壁消去・センサー反応）
   d ＞ しきい値 → 色不一致
```

- しきい値は外部パラメータとして定義

---

## 派生値

- **濃さ** = `(C + M + Y) / DamageMax`（独立パラメータではなく派生値）
