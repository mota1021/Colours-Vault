# 仕様: カラーシステム — index

色をゲーム内パラメータとして扱う基盤システム。光（加法混色）とインク（減法混色）は**二系統**で管理する。

- 光ドメイン（光が作用する側: 光・ガラス・ライト・光センサー・消える壁）= **RGB + Intensity 型**
- インクドメイン（減法混色）= **CMY 型**（継続）

## 光: RGB+Intensity 型

- 色パラメータ = **R / G / B 各 int32（0〜255）+ float Intensity（0.0〜∞）+ int32 DamageValue**
- **無色・白光** = `(R=255, G=255, B=255)`
- **しきい値**: 色一致判定の境界。外部パラメータとして定義

## インク: CMY 型

- 色パラメータ = **C / M / Y の独立した3つの int 値**（値域は任意、0〜255に縛らない）
- **無色** = `(C=0, M=0, Y=0)`
- **DamageMax**: オブジェクトごとの外部パラメータ。表示正規化・ダメージキャップに使用
- **しきい値**: 色一致判定の境界。外部パラメータとして定義
