# 仕様: カラーシステム — index

色をゲーム内パラメータとして扱う基盤システム。光（加法混色）とインク（減法混色）を統一的な CMY 型で管理する。

## CMY 型定義

- 色パラメータ = **C / M / Y の独立した3つの int 値**（値域は任意、0〜255に縛らない）
- **無色・白光** = `(C=0, M=0, Y=0)`
- **DamageMax**: オブジェクトごとの外部パラメータ。表示正規化・ダメージキャップに使用
- **しきい値**: 色一致判定の境界。外部パラメータとして定義

## CMY ↔ RGB 変換式

**CMY → RGB**（DamageMax で正規化）
```
R = 255 × (1 - C / DamageMax)
G = 255 × (1 - M / DamageMax)
B = 255 × (1 - Y / DamageMax)
```
結果は [0, 255] にクランプ。

**RGB → CMY**（光→インク変換時）
```
sum = (1 - R/255) + (1 - G/255) + (1 - B/255)

sum = 0（白光）の場合: インクを生まない
sum > 0 の場合:
  C = DV_光 × (1 - R/255) / sum
  M = DV_光 × (1 - G/255) / sum
  Y = DV_光 × (1 - B/255) / sum
```
C+M+Y = DV_光 が保たれる。CMY→RGB→CMY の往復で元の値に戻る。

## 派生値

- **濃さ** = `(C + M + Y) / DamageMax`（独立パラメータではなく派生値）
