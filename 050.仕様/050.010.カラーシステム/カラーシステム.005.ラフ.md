## やりたいこと・目的

光（加法混色）とインク（減法混色）の演算ルール・相互変換を一元管理する。
合成・減算・変換の規則を1か所にまとめ、整合性を保ちやすくする。

---

## ルール・挙動

### 光の演算

- 複数光の合成: 各光について normalize(RGB) × Intensity を計算して加算。合計ベクトルを再正規化して色方向とする。合成Intensity = Σ各光のIntensity。合成DamageValue = Σ各光のDamageValue
- 光の減算: RGBのみ減算（下限0クランプ）。Intensity・DamageValueは引かれる側（左辺）を維持する

### インクの演算

- インクの合成: CMY各値を加算する。DamageMaxは足される側（左辺）を引き継ぐ

### 変換

- CMY → RGB: R = 255 × (1 - C/DamageMax)（G, B も同様）。[0,255]クランプ
- RGB → CMY（光→インク）: sum = Σ(1-ch/255)。sum=0（白光）はインクなし。sum>0 のとき C = DV_光 × (1-R/255) / sum（M, Y も同様）
- インク → 光: 上記CMY→RGB変換でRGB算出。DV=C+M+Y。Intensity=デフォルト1.0（呼び出し側指定可）
- 色一致判定: 光・インクともにRGB空間に変換後、ユークリッド距離で判定。d = √(ΔR² + ΔG² + ΔB²)。d ≦ しきい値 → 一致

### 派生値

- 濃さ = (C + M + Y) / DamageMax
