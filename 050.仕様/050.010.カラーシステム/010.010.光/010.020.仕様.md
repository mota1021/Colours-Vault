## 挙動ルール

### 色の数値化方針

- 色パラメータ = **R / G / B 各 int32（0〜255）+ float Intensity + int32 DamageValue**（DamageValue の詳細は未決）
- **無色・白光** = `(R=255, G=255, B=255)`
- **Intensity**: 0.0〜∞（上限なし）

### 複数光の合成ルール

```
① 各光の RGB を [0, 1] に正規化（÷255）
② normalize(RGB) × Intensity を計算
③ 各光のベクトルを加算
④ 合計ベクトルを再正規化して色方向を決定
⑤ 合成 Intensity = Σ 各光の Intensity
```

- 合成結果を1つの光として壁・センサーに照射する

### 色一致判定ルール

```
① 光と対象の RGB をそれぞれ [0, 1] に正規化
② ユークリッド距離を計算: d = √(ΔR² + ΔG² + ΔB²)
③ d ≦ しきい値 → 色一致（壁消去・センサー反応）
   d ＞ しきい値 → 色不一致
```

| パラメータ | 備考 |

| R / G / B | 各 int32（0〜255） |
| Intensity | float（0.0〜∞） |
| DamageValue | int32。詳細は未決 |
| しきい値 | 色一致判定の境界。外部パラメータとして定義 |
