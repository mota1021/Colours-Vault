# 仕様: 光

## 概要・目的

色をゲーム内のパラメータとして数値管理する型を定義する。光（加法混色）を統一的なシステムで扱い、壁消去・色判定のすべてを同一の CMY 型で処理する。

## 挙動ルール

### 色の数値化方針（2026-06-18 確定）

- 色パラメータ = **C / M / Y の独立した3つの int 値**（非正規化。値の大きさが明るさ×色を表す）
- **内部は CMY で管理**。演算時は最大値で正規化して使用
- **濃さ = C + M + Y**（派生値。独立した4つ目のパラメータではない）
- **無色・白光** = `(C=0, M=0, Y=0)`（特殊値なし。2026-06-26 確定）

### 複数光の合成ルール（2026-06-26 確定）

現実の加法混色に従い、以下の順で計算する：

```
① 各光の CMY を最大値（外部パラメータ）で正規化
② 正規化した各光を RGB に変換: R = 1-C, G = 1-M, B = 1-Y
③ RGB 同士を加算し、各値を [0, 1] でクランプ
④ 合成 RGB を CMY に戻す: C = 1-R, M = 1-G, Y = 1-B
⑤ CMY を最大値でスケールして int に戻す
```

- 合成結果の CMY 1つとして壁・センサーに照射する

### 色一致判定ルール（2026-06-18 確定）

壁・キャラ・光、**すべて CMY int で統一管理**する。

```
① 光と対象の CMY をそれぞれ正規化
② ユークリッド距離を計算: d = √(ΔC² + ΔM² + ΔY²)
③ d ≦ しきい値 → 色一致（壁消去・センサー反応）
   d ＞ しきい値 → 色不一致
```

### 「黒」への対抗手段

- 特定属性（白光など）の照射範囲判定が**二重に重なっているか**で判定する
