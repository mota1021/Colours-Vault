# 仕様: 光

## 挙動ルール

### 色の数値化方針

- 色パラメータ = **R / G / B 各 int32（0〜255）+ float Intensity + int32 DamageValue**
- **無色・白光** = `(R=255, G=255, B=255)`
- **Intensity**: 0.0〜∞（上限なし）

### 複数光の合成ルール

```
① 各光の RGB を [0, 1] に正規化（÷255）
② normalize(RGB) × Intensity を計算
③ 各光のベクトルを加算
④ 合計ベクトルを再正規化して色方向を決定
⑤ 合成 Intensity = Σ 各光の Intensity
⑥ 合成 DamageValue = Σ 各光の DamageValue
```

- 合成結果を1つの光として壁・センサーに照射する

### 光の減算ルール

- RGB 各値を減算する（下限 0 にクランプ）
- Intensity・DamageValue は引かれる側（左辺）を維持する

### 色一致判定ルール

```
① 光と対象の RGB をそれぞれ [0, 1] に正規化
② ユークリッド距離を計算: d = √(ΔR² + ΔG² + ΔB²)
③ d ≦ しきい値 → 色一致（壁消去・センサー反応）
   d ＞ しきい値 → 色不一致
```

## パラメータ

| パラメータ | 備考 |
|---|---|
| R / G / B | 各 int32（0〜255） |
| Intensity | float（0.0〜∞） |
| DamageValue | int32。発生源から決まる（下記参照） |
| しきい値 | 色一致判定の境界。外部パラメータとして定義 |

### DamageValue の決まり方

| 光の発生源 | DamageValue |
|-----------|------------|
| 光源から発射 | 光源の外部パラメータをコピー |
| インクから変換 | インクの `C + M + Y` を引き継ぐ |

### インク → 光 変換

```
RGB:          CMY → RGB 変換式を使用（カラーシステム index 参照）
DamageValue:  C + M + Y（インクのDV）
Intensity:    デフォルト 1.0（呼び出し側が都度指定可）
```

### 光 → インク 変換

カラーシステム index の RGB → CMY 変換式を参照。
