# 演出・UI: 光の伝播

## ビームの見せ方

- 継続（透過後）ビームは色変化後の色で描画する。プレイヤーが「ガラスを通って色が変わったこと」を直接視認でき、パズルの手掛かりになる。

## 演出・SE

- 透過時の特別な演出・SEは不要（ガラス既決 2026-07-09）。
