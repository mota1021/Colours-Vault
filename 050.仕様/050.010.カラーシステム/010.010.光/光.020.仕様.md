# 仕様: 光

## 概要・目的

光の色をゲーム内のパラメータとして数値管理する。光（加法混色）を RGB+Intensity 型で扱い、壁消去・色判定を同一の型で処理する。

> ダメージ計算 → [[ダメージシステム.000.index|ダメージシステム]]
> 死亡条件 → [[死亡システム.000.index|死亡システム]]
> インク（減法混色）→ [[色.000.index|インク]]
> 演算・変換式 → [[カラーシステム.025.パラメータの計算仕様|パラメータの計算仕様]]

---

## 挙動ルール

### 色の数値化方針

- 色パラメータ = **R / G / B 各 int32（0〜255）+ float Intensity + int32 DamageValue**
- **無色・白光** = `(R=255, G=255, B=255)`
- **Intensity**: 0.0〜∞（上限なし）

---

## パラメータ

| パラメータ | 備考 |
|---|---|
| R / G / B | 各 int32（0〜255） |
| Intensity | float（0.0〜∞） |
| DamageValue | int32。発生源から決まる（下記参照） |
| しきい値 | 色一致判定の境界。外部パラメータとして定義 |

### DamageValue の決まり方

| 光の発生源 | DamageValue |
|-----------|------------|
| 光源から発射 | 光源の外部パラメータをコピー |
| インクから変換 | インクの `C + M + Y` を引き継ぐ |
