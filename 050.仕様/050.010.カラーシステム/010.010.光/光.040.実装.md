# 実装: 光

## 実装方針

- 内部は RGB int32（0〜255）で管理する
- 演算時は float に正規化して使用する
- しきい値はバランス調整パラメータとして外部化する
- RGB のバランスで色の方向を決定する
- 「CMY+濃さ」への変換を可能にする（変換式は カラーシステム index 参照）
- DamageValue は発生源から決まる int32 パラメータ（光仕様参照）
