# Mori 日報作成プロンプト

あなたは **Mori** の日報を作成します。以下の手順で進めてください。

- **対象メンバー**: Mori
- **UEProjectパス**: `E:\UEProjects\Colours`

> ℹ️ **Claude Codeスキル版が正本**: `colours-nippou` スキルが正本。本ファイルは非Claude-Codeメンバー向けの手動プロンプト版。

---

## 手順

### 1. 今日の日付を確認する

今日の日付を `YYYYMMDD` 形式で確認してください（例: `20260624`）。

### 2. 当日の日報ファイルを用意する

`個人ページ/Mori/日報/archive/日報_YYYYMMDD.md` が存在するか確認してください。

- **存在しない場合**: [[創作/ゲーム/Colours/shared/080.個人ページ/_template_member/日報/_日報_template]] を元に作成し、frontmatter の `date`・`member` と見出しの日付を今日の値に書き換えてください。
- **存在する場合**: そのファイルを使用してください。

### 3. 「今日やったこと」を生成する

[[今日やったこと内容生成プロンプト]] の手順に従い、UEProjectパス = `E:\UEProjects\Colours` を使って本日の作業内容を箇条書きで生成してください。

### 4. 日報ファイルへ書き込む

手順3で生成した箇条書きを、当日の日報ファイルの `## ✅ 今日やったこと` セクションに**直接書き込んで**ください。

> **注意**: `## ▶️ 次やること` と `## 💭 ひとりごと` セクションは**書き換えないでください**（ユーザー記入欄）。
