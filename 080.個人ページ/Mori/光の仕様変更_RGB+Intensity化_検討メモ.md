# 光の仕様変更: CMY型 → RGB(正規化)+Intensity への移行

## Context（なぜ変更するか）

現行の光は「C/M/Yの独立した3つのint値（非正規化、値の大きさ＝明るさ×色）」で管理し、
壁・キャラ・インクまで含めて**単一CMY型で統一**する設計。光のパラメータ管理を
**RGB(正規化して保持)＋Intensity倍率の4パラメータ**へ大幅変更したい。

これにより色相（正規化RGB）と明るさ（Intensity）が分離され、UE5の `FLinearColor`＋輝度スカラーに
素直に対応する一方、現行の「統一CMY型」設計思想・濃さ・合成・一致判定・ダメージなど広範囲に波及する。

### 確定済みスコープ
- **適用範囲＝「光が作用する側」のみ**: 光・ガラス・ライト・光センサー・消える壁を RGB(正規化)+Intensity 化。
- **インクは別系統として CMY 継続**（減法混色のため）。
- 結果としてカラー基底が**二系統に分裂**するため、「統一CMY型」の看板は下ろし、二系統＋境界（橋渡し）として再定義する。
- **Intensityがロジックに関与するか／見た目専用か は未確定** → 仕様に両論を「未決」として残し、末尾の要確認事項に集約。

## 変更方針（ファイル別）

> ラフ（`*.010.ラフ.md`）は**人間のみ編集**の規約。本変更は口頭指示が起点のため、
> AI生成側（020/030/040 と各index）を更新し、ラフへの反映は末尾「要確認事項」で扱う。

### 1. [[カラーシステム.000.index]]（基盤・最重要）
- 「光・インク・壁・キャラを統一CMY型で管理」→ **二系統**へ書き換え:
  - 光ドメイン（光が作用する側）= **RGB(正規化)+Intensity**
  - インクドメイン（減法混色）= **CMY 継続**
- 「CMY型定義」節を「光: RGB+Intensity型 / インク: CMY型」の2節構成に。
- 壁・キャラが両ドメインの作用を受ける場合の**橋渡し（変換方針）**を未決として明記。

### 2. [[光.020.仕様]]（光の本体）
- **色の数値化方針**: C/M/Y int → `RGB(正規化float) + Intensity(倍率スカラー)` の4パラメータ。
  - 正規化方式（max成分=1／ベクトル長=1／成分和=1）を定義（未決として候補提示）。
  - 白＝RGB(1,1,1)、無色/無光＝Intensity 0。**(0,0,0)の正規化＝ゼロ除算**の扱いを規定。
- **濃さ**: `C+M+Y` 廃止。`濃さ ≈ Intensity` とするか別定義かを未決で明記。
- **合成（加法混色）**: 「正規化→RGB加算→[0,1]クランプ→CMY戻し」を
  `各光を RGB×Intensity で実色化 → 加算 → 再正規化しIntensity抽出` へ改訂。
  **飽和（クランプ）モデル／HDR的加算（Intensity青天井）どちらか**を未決で両論併記。
- **色一致判定**: ユークリッド距離は正規化RGBで継続（CMYと幾何的に等価）。
  **Intensityを判定に含めるか（閾値の有無）**を未決で明記。
- **「黒」対抗（二重照射）**: ロジック不変、白光表現を RGB(1,1,1) ベースに更新。
- **パラメータ表**: 「CMY最大値」削除 → 「Intensityの値域・最大値」「しきい値」へ差し替え。

### 3. [[光.030.演出・UI]]
- 内部語彙を CMY → RGB/Intensity に更新（プレイヤー非提示の原則は維持）。
- 濃さゲージの扱いは Intensity 表示として未決継続。

### 4. [[光.040.実装]]
- 「内部はCMY int64」→「RGB(正規化float)+Intensity(float)」へ。
- UE5 `FLinearColor`（RGB）＋輝度スカラーへの整合を実装方針として明記（旧未決D-1の再検討機会）。

### 5. [[ライト.005.共通仕様]]
- 既存パラメータ「光の強さ」と色の Intensity の**二重定義を整理**。
  `光の強さ（器具輝度）× 距離減衰 × 色Intensity` の三重計上を避ける適用順序を定義（未決で方針提示）。
- 「色」パラメータの参照先を新型（RGB+Intensity）へ更新。

### 6. [[ガラス.020.仕様]]
- CMY混色例を RGB+Intensity 例へ書き換え。
- **既存例の数値破綻を修正**（「赤＋青→紫」と書かれているが現行式では実際はシアン／白黒になる）。
- パラメータ「ガラスの色（CMY）」→「ガラスの色（RGB）」。

### 7. [[消える壁.020.仕様]]
- 「光の色と壁の色が同じなら消える」の色表現を**光側（RGB）**に統一。壁色を RGB で保持。

### 8. [[光センサー.020.仕様]]
- 反応色条件を RGB 側で定義（未決の「任意色か特定色か」は維持）。

### 9. 周辺メモ（本変更では編集せず指摘のみ）
- ダメージ系（`050.040`）はラフに「総量を均等分割（青10→C5,M5）」のCMY前提ルールあり。仕様本体は空。
  Intensityベースへの再定式化が将来必要。

## ⚠ 要確認事項（未確定のまま残すもの・最終確認用）

1. **Intensityの役割**: ゲームロジック関与（閾値で壁消去/センサー反応・ダメージ量）か、見た目（輝度）専用か。
   → 濃さの定義・一致判定・距離減衰の意味・ダメージ式がすべてここに依存。
2. **加法混色モデル**: 合成時のIntensityは**飽和（[0,1]クランプ）**か**HDR的加算（青天井）**か。
3. **正規化方式**: max成分=1／ベクトル長=1／成分和=1 のいずれか。白・無色・黒(0,0,0)の表現と
   ゼロ除算回避の規定もここで確定。
4. **濃さの再定義**: `濃さ = Intensity` とみなすか、別概念にするか（廃止含む）。
5. **ライト「光の強さ」とIntensityの関係**: 別物（器具輝度×色強度）か統合か。距離減衰の適用箇所。
6. **二系統の橋渡し**: 壁・キャラが光(RGB)とインク(CMY)両方の作用を受ける場合の変換方針。
7. **インク側の扱い**: 今回はCMY据え置きで確定か。将来的に統一するかは別議題か。
8. **ダメージ「総量均等分割」ルール**: Intensityベースへどう再定式化するか（別セッション可）。
9. **ラフ更新の主体**: [[光.010.ラフ]] 等のラフ（人間のみ規約）に本変更を
   ユーザーが反映するか、AIが代筆してよいか。
