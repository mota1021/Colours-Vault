# {{MEMBER}} 日報作成プロンプト

あなたは **{{MEMBER}}** の日報を作成します。以下の手順で進めてください。

- **対象メンバー**: {{MEMBER}}
- **UEProjectパス**: `{{UE_PROJECT_PATH}}`

> 内容の生成規則は [[今日やったこと内容生成プロンプト]]。`colours-nippou` スキルと共通で使う。

---

## 手順

1. 対象日を確認する。指定がなければ実行環境の当日を使う。
2. [[今日やったこと内容生成プロンプト]] に、対象メンバー `{{MEMBER}}`、対象日、確認できた `shared/` ルートと上記UEProjectパスを渡し、実績を収集する。
3. 活動を確認できた日だけ、`shared/080.個人ページ/{{MEMBER}}/日報/archive/日報_YYYYMMDD.md` を用意する。存在すればそのファイルを使い、なければ [[創作/ゲーム/Colours/shared/080.個人ページ/_template_member/日報/_日報_template]] から日付・メンバーを設定して作成する。
4. 確認できた実績を `## ✅ 今日やったこと` へ書き込む。`## ▶️ 次やること` と `## 💭 ひとりごと` はユーザー記入欄として保持する。
5. 保存先と記録件数、取得できなかった履歴を報告する。履歴取得失敗を活動なしと扱わない。
