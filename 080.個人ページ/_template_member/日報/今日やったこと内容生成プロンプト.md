# 今日やったこと内容生成プロンプト

あなたは以下の手順で「今日やったこと」の箇条書きを生成してください。
このプロンプトは内容の生成のみを行います。ファイルへの書き込みは呼び出し元のプロンプトが行います。

---

## 入力

- **UEProjectパス**: 呼び出し元のプロンプトに記載されたパスを使用してください。

---

## 手順

### 1. shared\ 側の履歴を取得する

`D:\document\ObsidianVault\創作\ゲーム\Colours\shared` ディレクトリで以下を実行してください。

```
dv log
```

本日（今日の日付）のコミットを対象にしてください。

### 2. UEProject 側の履歴を取得する

呼び出し元に記載された UEProjectパス のディレクトリで `dv log` を実行してください。

> **注意**: `shared\` とは別の Diversion ワークスペースです。必ず UEProjectパスに cd してから実行してください。

本日（今日の日付）のコミットを対象にしてください。

### 3. 箇条書きを生成する

取得した両方の履歴から、おおまかな作業内容を箇条書きにまとめてください。

**方針**:
- 具体的なファイル名・コミットハッシュは不要
- 粒度の目安: 「◯◯機能の設計ドキュメントを更新」「◯◯のUE実装」
- 本日分のコミットが無いソースは箇条書きに含めない
- 出力は箇条書きのみ（見出しや説明文は付けない）
