# M3 検証用1ステージ

> **役割**: M2の縦スライス後に、ゲームに必要な要素をあらかた実装し、それらを1本の仮ステージへ組み込んで実際の使い方・組み合わせ・成立性を確かめるための検証フェーズ。
> **位置づけ**: ここで作るステージは正式なStage1ではなく、本採用を前提としない検証用ステージ。正式なStage1の設計・制作は、この検証結果を踏まえて後続フェーズで行う。

## 目的

- ゲーム全体に必要になる主要なプレイヤー操作・ギミック・戦闘などを、単体実装だけで終わらせず実際のプレイへ組み込んで確認する。
- モノを作り、実際にどう使えるかを組みながら確かめる。
- 組み合わせた結果から、不要な要素・不足している要素・改善が必要な要素を洗い出す。
- 正式ステージ制作へ入る前に、ゲームとして必要な部品と基本的な組み合わせ方を一通り成立させる。

## 進め方

1. 必要なゲーム要素を洗い出す。
2. 各要素について、必要に応じて仕様確定 → 実装方針確定 → 実装を行う。
3. レベル側では、体験設計 → 配置設計 → 実配置の順で検証用ステージへ組み込む。
4. 実際に通して遊び、個別要素と組み合わせの成立性を確認する。
5. 検証結果を次の正式ステージ制作計画へ反映する。

## 完成条件

- [ ] M3で検証対象とする主要ゲーム要素が洗い出されている。
- [ ] 対象要素が、仮ステージ内で実際に使用できる状態まで実装されている。
- [ ] 複数要素を組み合わせたプレイを1本のステージとして通して確認できる。
- [ ] 各要素について「使える／改善が必要／見送る」の判断材料が得られている。
- [ ] 正式なStage1制作へ進むための残課題と採用要素が整理されている。

## Stage1との関係

既存の `060.level_design/060.010.Stage1/` は、過去に作成したStage1案・設計資料として参照できるが、M3の仮ステージ構成そのものではない。

M3では、既存Stage1案をそのまま完成させることを目的にせず、必要なゲーム要素を検証するために使える部分だけを参照・再利用する。
