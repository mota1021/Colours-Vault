# 🎯 縦スライス（MVP / 北極星）: [[Colours]]

> **役割**: 「遊べる最小の一室」= プロジェクトの北極星。企画・実装の優先度に迷ったら **「この一室に効くか？」** で取捨する基準にする。
> **位置づけ**: [[ステージ1設計]]（10セクション）とは**独立した最小プロトタイプ**。ギミック①「光で壁を消す」の面白さの芯だけを切り出した検証用の一室。共有するのは中核機構（[[要チケット化リスト]] EW 消去壁・PL-3 携帯ライト・既存資産 `AErasableWall`）のみ。

---

## 目的
ギミック①「光で壁を消す」だけで、**拾う → 解く → 進む** の最小ループが成立することを実機で確認する。
システムを増やす前に「面白さの芯」がこの1部屋で立つかを検証する。

## 1部屋の構成（たたき台）
1. スタート地点にプレイヤー（白）。
2. 床に**携帯ライト**が落ちている → 拾う。
3. ライトを壁に向けて**床に置く（設置）**。設置後もライトは点灯し続け、向きを保って照射する。
4. 前方に**色付きの壁**が通路を塞ぐ。設置したライトの光と壁の色関係に応じて**穴が開く**。
5. 開いた穴を**通り抜けて**奥へ進む。
6. 奥の**ゴール**に到達でクリア。

## プレイヤー体験フロー（学習の流れ）
- 「光を当てると壁が消える」を**何も説明せず**視覚で理解させる（[[ステージ1設計]] S3 の意図）。
- 色違いの壁を1枚混ぜ「**消える壁／消えない壁**」を対比で気づかせる（色マッチング体験 = [[要チケット化リスト]] EW 消去壁 + CS 色照合 が担う）。

## 含む / 含まない（スコープの境界線）
- ✅ 含む: 携帯ライト1本・壁の部分消去・色マッチング判定・通り抜け・ゴール判定。
- ❌ 含まない（この縦スライスでは不要）: 戦闘・ダメージ・死亡条件（濃さ）・敵・HUD・サウンド・複数光源。
  - → 戦闘系（濃さ/死亡）はこの縦スライスのスコープ外（[[ステージ1設計]] 本編にも現状なし）。

## 完成条件（この縦スライスの「done」）
- [ ] 携帯ライトを拾える。
- [ ] ライトを壁に向けて床に**置ける（設置）**。設置後も点灯維持・向き保持で照射し続ける。
- [ ] 設置したライトの光が色関係に応じて壁に穴が開く（可逆消去: 光が当たっている間だけ消える = EW-1 + EW-5）。
- [ ] 開いた穴を通り抜けられ、塞がった部分は通れない。
- [ ] ゴール到達でクリア状態になる。
- [ ] 上記が**1部屋を通しで**破綻なく遊べる。
