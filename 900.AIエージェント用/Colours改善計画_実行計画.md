## Task 4b: 新スキル `colours-spec-interview` 作成

- [x] Task 4b

**対象ファイル**: `.claude/skills/colours-spec-interview/SKILL.md`（新規）

**作業内容**: 以下のフローを持つスキルを定義する。
1. 対象仕様の確認 → テンプレートからフォルダ生成（既存の企画モード手順を踏襲）
2. 関連ファイルの事前Read: `決定ログ.md`・隣接仕様・カテゴリindex（矛盾チェックの材料）
3. **カテゴリ別チェックリスト**（スキル内に定義: 例・ギミック系 = トリガー条件/状態遷移/色との相互作用/失敗・境界時の挙動/演出・SE/実装クラス方針/外部化パラメータ）に沿って**一問一答**でヒアリング。既存の未決事項一問一答文化と同型
4. 回答をそのまま `NNN.010.ラフ.md` に議事録として記録（人間の作文ゼロ。箇条書きメモの持ち込みも可）
5. 全観点消化後、ラフから 020/030/040 を生成（既存の振り分け基準を使用）
6. 回答不能だった観点は `[未決]` としてラフの未決セクションへ、確定事項は `決定ログ.md` へappend、SPチケット状態の更新を案内
- 禁止事項は現行スキルを踏襲（推測補完しない・回答にない内容を仕様に入れない）

**完了条件**: スキルが利用可能スキル一覧に現れ、ドライラン（4d）で全ステップが通ること
