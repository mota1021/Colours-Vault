# 実行計画: 光の多ホップ伝播

> このファイルの旧計画は廃止済みです。現行の実装計画は [[創作/ゲーム/Colours/shared/900.AIエージェント用/非同期Task/光の多ホップ伝播/実装計画|光の多ホップ伝播 — 実装計画]] を参照してください。

## 廃止理由

旧計画で検討していた以下の方針は、後続の設計見直しで撤回されています。

- ガラス出射面から継続レイを再発射する多ホップループ
- 伝播処理の専用 Component / UObject 化
- 透過体の汎用 Interface 化
- 将来の反射・屈折を前提にした伝播基盤

Stage1 の現在要件では進行方向を変化させないため、現行計画では `AColoursLightSourceBase` 内部の処理と `LineTraceMultiByChannel` を用いる最小構成を採用しています。

旧計画の詳細が必要な場合は archive の履歴を参照し、実装判断には使用しないでください。
