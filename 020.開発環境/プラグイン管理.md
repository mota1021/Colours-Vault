## トラブル事例 — 同梱プラグインのネスト `.gitignore`

**発生日**: 2026-06-25〜26（dv.commit.17〜23）

### 症状
リポジトリをクローンした先で UE プロジェクトが起動できなかった。
プラグインのビルドを求められ、C++ コンパイラのない環境では続行不可能だった。

### 直接原因
`Plugins/VisualStudioTools` の UHT 生成ヘッダ（`Intermediate/`）と
プラグイン DLL（`Binaries/Win64/*.dll`・`*.modules`）が Diversion リポジトリに含まれていなかった。

### 根本原因
`VisualStudioTools` プラグインは GitHub の UnrealEngine テンプレート由来の
**独自 `.gitignore`** を内包しており、その中の以下2行が有効（コメントアウトされていない）だった。

```
Intermediate/*
Plugins/*/Intermediate/*
```

**Diversion はサブフォルダのネストした `.gitignore` を尊重する**ため、
プラグイン配下の `Intermediate/` が除外されリポジトリに入らなかった。

### なぜ手こずったか
ルート `.dvignore` に `!Plugins/**/Intermediate/**` のホワイトリストを追加しても無効だった。
ネストした `.gitignore` による除外がルートのホワイトリストより優先されるため。

### 解決方法
`Plugins/VisualStudioTools/.gitignore` の該当2行をコメントアウト（`#` を先頭に追加）し、
プラグインの `Intermediate/`・`Binaries/` を `dv commit -a` でコミット。

### 教訓（新プラグインを同梱するときの必須チェック）
1. プラグインフォルダ内に `.gitignore` / `.dvignore` が存在しないか確認する。
2. あれば `Intermediate` / `Binaries` を除外している行をコメントアウトする。
3. プラグインのビルド成果物を Diversion にコミットし、クローン先で起動できることを確認する。
