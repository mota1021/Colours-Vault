# 色・光のあそび

> **役割**: Colours で使える「色・光を利用した遊び」を整理する企画資料。
> ここにある内容は、現実の光学・色彩現象をそのまま再現するための仕様ではない。直感的に理解できる形へゲーム向けに単純化し、組み合わせてギミックへ発展させる。
> 個別ギミックの確定ルールは `050.仕様/`、ステージでの採用・配置は `060.level_design/` を正本とする。

## 遊びの核

**光と色の性質を組み合わせてギミックを解き、環境を変化させながら先へ進む。**

単純な「色合わせ」だけではなく、光の進み方・変化の仕方、色同士の関係、物質との相互作用を組み合わせて解法を作ることを中心にする。

## 色ダメージ・色アクション・属性強化の循環（企画メモ）

- プレイヤーはダメージを受けると、その攻撃に対応する色が身体に蓄積する。
- 色の蓄積そのものがダメージ状態を表す。
- 蓄積した色は、対応するアクションを使う際に少量消費できる。
- 色を消費すると身体からその色が減るため、色アクションの使用は回復も兼ねる。
- ただし1回あたりの消費量は小さく、色アクションだけで短時間に全回復することは難しい。
- パワーアップ前は、色を所持しているときだけ、その色を消費して「色のアクション」として発動する。
- パワーアップ後は、対応アクションへ属性効果が追加される。
  - 赤：炎
  - 青：水
  - 緑：植物
- 青属性の冷却・凍結は、水から派生するギミック候補として扱う。
- パワーアップ後も、色を所持している場合はその色を消費して通常より強い属性効果を発生させる。
- 色を所持していない場合でも、対応アクションの最終弾では小さな属性効果が発生する。
- これにより、パワーアップは「色を持っていないと何もできない状態」から「基礎属性は常時使え、色を持っていると強化できる状態」への拡張になる。
- ダメージ、色の蓄積、アクション、回復、属性強化を同じ「色」のシステムでつなぐ。

## 利用する性質

### 光の性質

- **直進**
  - 光は基本的にまっすぐ進む。
  - 光路を読む、遮る、通すといった基礎になる。
- **反射**
  - 鏡などで光の進行方向を変える。
  - 複数回の反射で離れた対象へ光を届ける。
- **屈折**
  - 水やガラスなどを通して光の進行方向を変える。
  - 入射位置や角度によって到達先が変わる遊びに使う。
- **散乱**
  - 光を広げる、届き方を変える。
  - 一点照射と広範囲照射の使い分けに使う。
- **透過**
  - ガラス、水などを通過させる。
  - 通過時に色や進行方向が変わる組み合わせへ発展させる。
- **混色**
  - 複数の光を重ねて別の色を作る。
  - 必要な色をその場で作って対象へ当てる。
- **集光**
  - レンズなどで光を集める。
  - 焦点位置を動かし、狙った場所だけを強く照らす。
- **光と熱**
  - 強い光や集光によって対象を熱する。
  - 現実の挙動を厳密に再現せず、ゲームルールとして分かりやすく扱う。
- **影・暗闇**
  - 光を当てて影を消す。
  - 影が光を吸収する、暗闇の中では特定の対象が見えなくなるなど、ゲーム向けに単純化したルールとして扱う。

### 色の性質

- **混色**
  - 光の加法混色、インクや塗料の減法混色を使い分ける。
- **相対色**
  - 周囲の色との関係を利用する。
  - 具体的なゲームルールは今後定義する。
- **補色**
  - 補色関係をギミックの反応条件や色変化に利用する。
- **同色／異色の関係**
  - 同じ色なら通る、消える、反応するなど、直感的な関係を利用する。
- **色の付与・除去**
  - 対象へ色を付ける、別の色へ変える、水などで色を落とす。
- **色を介した見え方の変化**
  - 同色のガラス越しに、向こう側の同色物体が見えなくなる。
  - 条件によって、向こう側の同色物体が白く見えるなど、色関係によって認識が変わる遊びに使う。

## プレイヤーが行う操作

### 光源を操作する

- 携帯ライトを拾う、持つ、置く、向きを変える。
- 固定ライトやサーチライトの向きを変える。
- 炎を光源として利用する。
- 光源そのものを移動させ、照射位置を変える。

### 光路を操作する

- 鏡などを動かして**反射**させる。
- 水や透明物を利用して**屈折**させる。
- 光を遮る物体を移動させ、光路を開閉する。
- 光が通る場所と通らない場所を作る。

### 光の色を操作する

- 光に**フィルター**をかける。
- 色付きガラスを通す。
- **プリズム**を操作する。
- 複数の光を重ねて混色する。
- 水にインクをにじませ、透過する光の色や見え方を変える。

### 光の広がり・強さを操作する

- **レンズ**を操作して焦点位置をずらす。
- 光を集める、広げる。
- 集光して対象を熱する。
- 散乱させ、広い範囲へ光を届ける。

### 色そのものを操作する

- オブジェクトへ色を塗る。
- インクを混ぜる。
- 水で洗って色を落とす。
- プレイヤー自身の色が変化する。
- 攻撃によって対象の色を変える。
- インクを使って塗るほど、プレイヤー自身の色や保有インクが減る。

### 温度・物質状態を操作する

- 炎などで**熱する**。
- **冷やす**。
- 熱・冷却による状態変化を、光や色のギミックと組み合わせる。
- 水を温める。
- 炎色反応で色を変える。
- 温度計などの目盛りを変化させる。
- 水を溜める、濁らせる、洗い流すなど、水そのものも媒質・道具として使う。
- 水を流す。
- 床や物体を濡らす。
- 濡れた床を滑りやすくする。

## 遊びへの展開

### 道を作る

- 光を当てた部分の壁を消して通路を作る。
- 光を外すと壁が戻る可逆変化を利用する。
- 遠くからライトを配置し、自分が通れる穴を作る。
- 光で足場を消す／復活させ、タイミングを見て進む。

### 必要な色を作る

- フィルターを通して光の色を変える。
- 複数の光を混ぜる。
- 色付きガラスや水＋インクを通す。
- プリズムで光を分け、必要な光だけを利用する。

### 光を目的地まで運ぶ

- 鏡を使って反射させる。
- 水・ガラス・レンズで屈折させる。
- 複数の反射・屈折・透過を連鎖させる。
- 光路上の遮蔽物を動かして経路を成立させる。

### 光を別の作用へ変える

- レンズで集光して対象を熱する。
- 炎を「光源」と「熱源」の両方として使う。
- 熱する／冷やすことで物体の状態を変え、その結果として光路を変える。

### 見え方・発見に使う

- 同色の背景や色ガラスを利用して姿を見えにくくする。
- 同色のガラス越しに、向こう側の同色物体を消して見せる。
- 条件によって、同色物体を白く見せる。
- 黒や影を利用したステルスを作る。
- 影に入って一定時間経過すると姿が消える。
- 光を当てて影を消し、隠れていた対象を露出させる。
- 光を当てることで見えなかったものを見えるようにする。
- 色フィルター越しに見ることで、通常とは異なる情報が見えるようにする。
- 暗いステージで、明るさそのものを攻略情報として利用する。
- モニターの明るさ設定を利用して、見える／見えない情報を作る案も候補とする。

### プレイヤー自身をギミックの一部にする

- 自身の色が変わる。
- 自分と同じ色の光を通過する／利用する。
- 自分と同色のレーザーに乗る。
- 色を受けすぎる、混ざりすぎるなど、プレイヤーの状態そのものをパズル条件にする。

### 戦闘と接続する

- 攻撃した色を敵へ蓄積させる。
- 敵や対象の色を変え、環境ギミックと干渉できる状態にする。
- 自分が受けた色を利用して攻撃へ変換する。
- 戦闘で色を変え、その結果が移動・ステルス・パズルにも影響する。
- サーチライトで敵を発見し、タレットなど別の装置に攻撃させる。
- 敵の色によって、当てるサーチライトや使う攻撃方法を変える。
- 黒い敵を二方向から白色光で照らし、影をなくすことで倒す。

### 風・砂嵐と組み合わせる

- 向かい風で減速、追い風で加速する。
- 砂に覆われて対象の色が判別できなくなる。
- 水で砂を洗い流して、本来の色や機能を取り戻す。
- 砂が積もる／吹き飛ぶことで地形や遮蔽物が変化する。
- 砂嵐によって周囲が暗くなり、視認性が落ちる。
- 砂嵐で水が濁り、光を通しにくくする。

## 複合ギミック例

以下は組み合わせ方の例であり、確定仕様ではない。

1. **フィルター → 反射 → センサー**
   - 白い光へフィルターをかけて必要な色を作る。
   - 鏡で反射させ、離れたセンサーへ当てる。

2. **プリズム → 必要色の選択 → 壁消去**
   - 白い光をプリズムで分ける。
   - 必要な色だけを壁へ導き、通路を作る。

3. **水＋インク → 透過光の変化 → ギミック作動**
   - 水へインクを加える。
   - 水を通った光の色を変え、対応する壁やセンサーへ当てる。
   - 水で洗えば元に戻せる。

4. **レンズ → 集光 → 加熱**
   - レンズの位置を変えて焦点を合わせる。
   - 対象を熱して状態を変える。
   - 変化した対象が光を通す、遮る、反射するなど次の作用へつながる。

5. **炎 → 照明＋加熱**
   - 炎の色・光でギミックへ干渉する。
   - 同時に熱源として別の対象も変化させる。

6. **自身の色変更 → 移動／ステルス**
   - プレイヤーの色を変える。
   - 同色レーザーを利用して移動する、背景へ溶け込むなど別の遊びへつなげる。

7. **攻撃 → 対象の色変更 → 環境利用**
   - 敵やオブジェクトへ攻撃して色を変える。
   - 変えた色によって光への反応や通過条件を変え、パズルの一部として利用する。

8. **影 → 二方向照射 → 黒い敵を倒す**
   - 一方向からの光では影が残る。
   - 二方向から白色光を当てて影を消し、黒い敵を露出させて倒す。

9. **砂嵐 → 色判別不能 → 水で洗う**
   - 砂に覆われた対象は色が分からず、そのままでは正しい光を選べない。
   - 水で砂を落とし、本来の色を確認してから攻略する。

10. **水 → 濡れた床 → 移動変化**
   - 水を流して床を濡らす。
   - 滑りやすくなった床を利用して、通常届かない場所まで移動する。

11. **サーチライト → 敵発見 → タレット**
   - サーチライトで敵を照らして位置を特定する。
   - 発見状態をトリガーに、別の装置から攻撃する。

## 現行資料ですでに使われている遊び

以下は現行の仕様・レベル設計ですでに具体化されている。

- 携帯ライト／固定ライトを操作する。
- 光を当てた部分の壁を消す。
- 光を外すと壁が復元する。
- 光と対象の色関係で反応を変える。
- 光センサーへ光を当てて扉を開ける。
- 色付きガラスを通して光の色を変える。
- 動く光によって足場が消えるタイミングアクション。
- 光・色のルールを説明文ではなく、実際の挙動を見せて学ばせる。

## 旧アイデアプールから引き継ぐ候補

- 自キャラと同じ色のレーザーに乗る。
- 黒は影の中で姿を消す。
- 影に入って一定時間経過すると姿が消える。
- 光を当てて影を消す。
- 影が光を吸収する。
- 同色の色ガラスをカメラとの間に挟むと敵からも見えなくなる。
- 同色ガラス越しに、向こう側の同色物体が消える／白く見える。
- 自キャラが筆になり、インクをつけて塗る。
- 歩いた場所へインクを塗る。
- インクは水で落ちる。
- インクを混ぜると黒くなる。
- 砂嵐で色が分かりにくくなる。
- 砂嵐で水が濁り、光を通しにくくなる。
- 大雨でインクが落ちる、水が溜まる。
- 雨によってステルス中の位置が分かる。
- 水を流す、床を濡らす、滑らせる。
- 炎を赤い光・燃焼・加熱・色変化に利用する。
- 炎で水を温める。
- 炎色反応や温度計の目盛り変化を利用する。
- 向かい風／追い風で移動速度を変える。
- 砂に覆われて色判定できない状態を作る。
- 砂を水で洗い流す。
- 砂が積もる／吹き飛ぶことで地形を変える。
- 暗いステージや明るさ設定を利用した見え方の遊びを作る。
- サーチライトで敵を発見し、タレットなどと連動させる。
- 敵の色に応じて、当てる光や攻撃方法を変える。
- 高出力レーザーで壁へ穴を開け、時間経過で穴が閉じる。
- 敵を攻撃すると攻撃した色が敵へ蓄積する。
- 自分の色を抽出して特殊攻撃へ使う。
- 色攻撃や色許容量を成長要素へつなげる。

## 発展の考え方

旧資料では、遊びの拡張を以下のように段階化する案があった。

1. **光**
   - 光の基本的な操作と加法混色を学ぶ。
2. **インク**
   - 色を塗る、混ぜる、洗うという減法混色の遊びを追加する。
3. **光＋インク**
   - 光と物質、加法混色と減法混色を組み合わせた複合ギミックへ進む。

この段階構造は候補として保持し、企画書でゲーム全体の構成を整理するときに再検討する。
