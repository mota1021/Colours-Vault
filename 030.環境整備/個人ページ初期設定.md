# Colours — 個人ページ初期設定

初回参加時に、自分用の個人ページを作る手順。

## 1. メンバーテンプレートを丸ごとコピーする

`080.個人ページ/_template_member/` をディレクトリごとコピーし、同じ `080.個人ページ/` 直下へ置く。

テンプレート自体は残し、移動や名前変更はしない。

## 2. コピーしたディレクトリを自分の名前に変更する

コピーした `_template_member` ディレクトリを、自分の名前へ変更する。

例:

```
080.個人ページ/Hiruta/
```

すでに自分の名前のディレクトリがある場合は、新しくコピーせず既存のものを使う。

## 3. 自分の名前を設定する

コピー先の `スタートアップ/作業興味アンケート.md` を開き、frontmatter の `member` を自分の名前へ変更する。

例:

```yaml
member: Hiruta
```

## 4. 作業興味アンケートを記入する

`スタートアップ/作業興味アンケート.md` の各項目へ回答する。

記入後は保存し、Diversion に変更を反映する。
