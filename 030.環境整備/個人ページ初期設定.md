# Colours — 個人ページ初期設定

初回参加時に、自分用の個人ページを作る手順。

## 1. 自分用ディレクトリを作る

`080.個人ページ/` の直下に、自分の名前のディレクトリを作る。

例:

```
080.個人ページ/Hiruta/
```

すでに自分の名前のディレクトリがある場合は、新しく作らず既存のものを使う。

## 2. スタートアップ用ファイルをコピーする

以下のテンプレートを、

```
080.個人ページ/_template_member/スタートアップ/作業興味アンケート.md
```

自分のディレクトリ配下へコピーする。

```
080.個人ページ/<自分の名前>/スタートアップ/作業興味アンケート.md
```

## 3. 自分の名前を設定する

コピーした `作業興味アンケート.md` の frontmatter にある `member` を自分の名前へ変更する。

例:

```yaml
member: Hiruta
```

## 4. 作業興味アンケートを記入する

そのまま `作業興味アンケート.md` の各項目へ回答する。

記入後は保存し、Diversion に変更を反映する。

日報など、個人ページ内の他のファイルは必要になった時点で追加する。
