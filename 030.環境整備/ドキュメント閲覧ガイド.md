# Colours — ドキュメント閲覧ガイド

Diversion の `Colours-Vault` リポジトリにあるドキュメントを閲覧するための環境セットアップ手順。

---

## 1. セットアップ手順

### 1-1. Obsidian をインストールする

- [Obsidian 公式ダウンロードページ](https://obsidian.md/download) からインストーラーを取得し、インストールする。無償。

### 1-2. Diversion (dv) をインストールする

- [Diversion 公式セットアップページ](https://app.diversion.dev/welcome) からインストーラーを取得し、インストールする。
- インストール後、`dv --version` でバージョンが表示されることを確認。

### 1-3. Colours-Vault リポジトリをローカルに同期する

Diversion にログインし、`Colours-Vault` リポジトリを任意のローカルフォルダに同期する。

```
dv login
dv clone Colours-Vault <同期先フォルダ>
```

以後の更新は、同期先フォルダで以下を実行して取得する:

```
dv pull
```

### 1-4. 同期先フォルダを Vault として開く

1. Obsidian を起動し「Open folder as vault」を選択。
2. 手順1-3で `Colours-Vault` を同期したフォルダを指定する。
3. Vault が開いたら完了。

### 1-5. Dataview プラグインを導入する

Obsidian の設定はリポジトリと同期されないため、各自でインストールする。

1. 設定 → コミュニティプラグイン を開き、制限モードをオフにする。
2. 「閲覧」から `Dataview` を検索し、インストール → 有効化。
3. `未決事項一覧` などの自動集約ビューが正しく表示されれば完了。
