# Colours — 実装環境セットアップ

Colours の UE プロジェクトをローカルで開発・実行できる状態にするための手順。

使用するエンジンバージョンの正本は [[020.開発環境/エンジンバージョン方針|エンジンバージョン方針]] と UE プロジェクトの `Colours.uproject`。現在は **Unreal Engine 5.8** を使用する。

## 1. Visual Studio を導入する

C++ プロジェクトのため、Visual Studio をインストールする。

- [Visual Studio ダウンロード](https://visualstudio.microsoft.com/downloads/)
- Visual Studio Installer で **「C++ によるゲーム開発」** ワークロードを有効にする。
- Unreal Engine 向けの Visual Studio Tools、デバッガーツール、Windows SDK も有効にする。
- 詳細は [Microsoft の Unreal Engine 向け Visual Studio セットアップ手順](https://learn.microsoft.com/ja-jp/visualstudio/gamedev/unreal/get-started/vs-tools-unreal-install) を参照する。

## 2. Unreal Engine 5.8 をインストールする

1. [Epic Games Launcher / Unreal Engine インストール手順](https://dev.epicgames.com/documentation/ja-jp/unreal-engine/install-unreal-engine) に従って Epic Games Launcher をインストールする。
2. Epic Games Launcher にサインインする。
3. Unreal Engine → Library を開く。
4. Engine Version を追加し、**Unreal Engine 5.8** を選んでインストールする。

別バージョンで代用しない。

## 3. 実装リポジトリを同期する

Diversion で `Colours` リポジトリが見えることを確認し、任意のローカルフォルダへ clone / sync する。

見えない場合は新しいリポジトリを作らず、招待した人へ連絡する。

CLI を使う場合:

```
dv clone Colours <同期先フォルダ>
```

以後、この同期先がチーム実装の作業場所になる。

## 4. UE プロジェクトを開く

同期先にある `Colours.uproject` を Unreal Engine 5.8 で開く。

初回起動時に生成やコンパイルが必要になった場合は、Visual Studio の C++ 開発環境が導入済みであることを確認してから進める。

## 5. 初期確認

以下を確認できれば実装環境の導入は完了。

- `Colours.uproject` が Unreal Engine 5.8 で開く。
- プロジェクトがエディタまで起動する。
- PIE を開始できる。
- Diversion 上で `Colours` の workspace として認識されている。

プラグインやエンジンバージョンを独自判断で追加・変更しない。問題が起きた場合は [[020.開発環境/プラグイン管理|プラグイン管理]] と [[020.開発環境/エンジンバージョン方針|エンジンバージョン方針]] を確認する。
