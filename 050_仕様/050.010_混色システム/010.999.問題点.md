# 仕様の問題点: 混色システム / CS-1 色の型定義

> CS-1 実装前に解決が必要な不明点・不足点の一覧。
> 解決したら該当項目をチェックし、決定内容を [[決定ログ]] と [[010.020.仕様]] に反映する。

---

## A. 仕様書の整合性問題

### A-1. ダメージ/死亡システムのスコープが曖昧
- `010.020.仕様` に「ダメージ計算ルール」「死亡条件（濃さ上限）」が記載されている
- 一方、[[縦スライス_MVP]] に **「戦闘・ダメージ・死亡条件（濃さ）はスコープ外。ステージ1本編にも現状なし」** と明記されている
- → **CS-1 の実装対象にダメージ/死亡システムを含めるか否かが判断できない状態**

### A-2. インク（減法混色）のサポート要否が未定
- 混色システム基本方針に「インク: 減法混色（ペン、インク、水）」が列挙されているが、Stage 1にインクギミックは存在しない
- → **CS-1 の型がインク混色をサポートする必要があるか未記載**

---

## B. 型の定義に関する欠落

### B-1. 値の型・値域が未定義
- Stage 1 は赤・青の2色のみ（2026-06-21 確定）。CMY 連続値より離散 enum (`Red / Blue / Purple / ...`) の方がシンプルな可能性があるが方針が未確定
- → **実装する前に値域と型を確定する必要がある**

### B-2. 加法混色の演算ルールが未記載
- CS-2「ガラス透過: 赤ガラス＋青光＝紫」は CMY 値同士の加算になるが、仕様に具体的な計算式がない
- クランプ（上限）処理の有無・方法も未定
- → **CS-2 実装前に演算ルールを仕様化する必要がある**

### B-3. 「白光」「無色」の CMY 表現が未記載
- 白色光や「色なし」状態の CMY 値が仕様に出てこない（`(0,0,0)` か特殊値か）
- → **白光・無色の扱いを定義する必要がある**

---

## C. 他チケットとの境界が不明

### C-1. 照合判定（CS-3）との責任分界が未定義
- ユークリッド距離による色一致判定を CS-1 の型のメソッドとして持つのか、CS-3 で実装するのか記載なし
- しきい値を型に持たせるか外部パラメータとするかも未定
- → **CS-1 と CS-3 の設計を同時に検討する必要がある**

### C-2. 光センサーの色条件が未決（CS-3 の前提）
- [[030.030_光センサー/030.000.index|光センサー]] に「反応する光の色条件（任意の色／特定の色のみ）は未決」と明記
- CS-3 はこの条件を前提とするため、CS-1/CS-3 実装前に確定が必要
- → **光センサーの色条件を先に仕様化する**

### C-3. 消える壁の可逆/不可逆の切り替え条件が未決
- [[030.020_消える壁/020.000.index|消える壁]] に「可逆/不可逆の切り替え条件（光の種類・壁の属性など）は未決」と明記
- 切り替えに色の種類が関係する場合、型設計に影響する可能性がある

---

## D. UE5 実装要件の欠落

### D-1. UE5 との統合方針が未記載
- `USTRUCT` か `UENUM` か未定
- Blueprint 公開の要否（`BlueprintType`）未定
- `FLinearColor` / `FColor` との変換関係が未記載
- → **実装前に UE5 の型方針を決定する必要がある**

## 優先度まとめ

| 優先 | 項目 | 理由 |
|---|---|---|
| 高 | A-1 | 型のスコープ自体が変わる |

| 高 | C-1 | CS-1 と CS-3 を切り離せない |
| 中 | C-2 | CS-3 の前提条件。CS-3 着手前に解決 |
| 中 | B-2 | CS-2 着手前に解決 |
| 低 | A-2, B-3, C-3, D-1 | CS-1 の基本形が固まってから検討 |
