# 混色システム

## 基本方針（オブジェクト単位）

エリア単位ではなく、**干渉するオブジェクトの種類**によって計算式を使い分ける。

| 種類 | 混色方式 | 具体例 |
|---|---|---|
| 光 | 加法混色 | レーザー、懐中電灯、サーチライト |
| インク | 減法混色 | ペン、インク、水 |

## 「黒」への対抗手段

- 特定の属性（白光など）の照射範囲判定が**二重に重なっているか**で撃破可否を判定する。
- パズル的なスイッチ操作と、アクション的な位置取り（自機スキルと環境の組み合わせ）の両方を採用。

## 色の数値化方針（2026-06-18 確定）

- 色パラメータ = **C / M / Y の独立した3つの int 値**。各々が独立したゲージとして機能する
- **内部は CMY で管理**、表示時のみ RGB 変換（R=1-C, G=1-M, B=1-Y）
- プレイヤーには「CMY」という言葉を出さない。見た目の色で直感的に把握させる
- **濃さ = C + M + Y**（派生値。独立した4つ目のパラメータではない）

## ダメージ計算ルール（2026-06-18 確定）

```
単色攻撃（シアン10）→ C+10,       濃さ+10
複色攻撃（青10）    → C+5, M+5,   濃さ+10  ← 合計濃さは同じ
```

- 攻撃の色を CMY で表現し、**対応するゲージのみ**増加（他ゲージへの波及なし）
- 複色攻撃は総量を構成色で均等分割する

## 死亡条件（2026-06-18 確定）

- **白スタート**：CMY = (0, 0, 0)、濃さ = 0
- **死亡**：濃さ（C+M+Y）が上限に達したとき
- 上限の初期値 = 100。**パワーアップで拡張可能**（色許容量の成長要素）

## 光 × 色族 干渉ルール（2026-06-18 確定）

壁・キャラ・光、**すべて CMY で統一管理**する。

```
① 光の RGB → CMY に変換
② 光の CMY とターゲットの CMY のユークリッド距離を計算
   d = √(ΔC² + ΔM² + ΔY²)
③ d ≦ しきい値  → すり抜け（ノーダメージ）
   d ＞ しきい値  → CMY ダメージ適用・濃さ増加
```

- 自分と同じ色の光は通り抜ける（直感ルール：「同じ色は当たらない」）
- しきい値はバランス調整パラメータとして外部化する
