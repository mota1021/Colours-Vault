# Colours — プラグイン管理

> 正本は `E:\UEProjects\Colours\Colours.uproject` の `"Plugins"` セクション。
> このファイルは有効プラグインの一覧・用途・追加経緯を記録する台帳。

---

## 現在有効なプラグイン

| プラグイン名 | 用途 | 追加理由 |
|---|---|---|
| `ModelingToolsEditorMode` | UEエディタ上でのメッシュ編集・モデリング | ジオメトリ操作のため |
| `GeometryScripting` | C++/BPからジオメトリを動的生成・編集 | 壁消去メッシュの動的生成のため |
| `VisualStudioTools` | UE↔Visual Studio の連携強化 | C++開発環境のため |
| `CommonUI` | クロスプラットフォーム対応UIフレームワーク | UI実装のため |
| `Diversion` | バージョン管理（Diversion連携） | プロジェクト管理のため |

## 無効だが追加済みのプラグイン

| プラグイン名 | 用途 | 有効化予定 |
|---|---|---|
| `ModelContextProtocol` | UE MCP連携（AIツールからUEを操作） | UE5.8移行 + Diversion対応後 |

---

## 運用ルール

- プラグインの追加・削除は **Mori がオーナー**。
- 変更時は `決定ログ.md` に記録する（名前・用途・追加/削除理由）。
- **PIEクラッシュ時は最新のプラグイン変更を最初に疑う**。
- 有効プラグインが増えた場合はこのファイルの一覧を更新する。
