# 日報生成プロンプト

このプロンプトを Claude に渡すと、Diversion 履歴を元に「今日やったこと」の箇条書きを生成してくれる。
生成後は `_日報_template.md` の「今日やったこと」セクションに貼り付けて使う。

---

## Claude へのプロンプト（コピーして貼り付け）

```
以下の手順で今日の日報（「今日やったこと」セクション）を作成してください。

## 手順

1. `shared\` のルート（D:\document\ObsidianVault\創作\ゲーム\Colours\shared）で以下を実行：
   ```
   dv log --since=today
   ```
   ※ 設計ドキュメント・Vault側の作業履歴

2. 個人ページの「UEProjectパス」で以下を実行：
   ```
   dv log --since=today
   ```
   ※ UE実装側の作業履歴（UEProjectパスは各自の日報インデックスを参照）

3. 両方の履歴を合わせて「今日やったこと」を箇条書きにまとめる

## 方針
- おおまかな内容でよい（具体的なファイル名・コミットハッシュは不要）
- 「◯◯機能の設計ドキュメント更新」「◯◯のUE実装」のような粒度
- 何もない場合はそのソースを「(変更なし)」と記載
- 出力は箇条書きのみ（見出しや説明文は不要）
```

---

## 補足

- `dv log` は Diversion のコミット履歴を表示するコマンド
- **`shared\` と UEProject は別々の Diversion ワークスペース**なので、それぞれのディレクトリで実行する必要がある
- UEProjectパスは各自の [[個人ページ/Mori/日報/日報インデックス|日報インデックス]] の「環境設定」を参照
- `--since=today` が効かない場合は `dv log` の最新数件を確認してもらえばよい
